# hello-node — ShipHub A2 sample

Minimal Node HTTP app with a Dockerfile for Phase T3 demo.

## Demo A2

1. Push this folder to a GitHub repository (or copy files into a new repo).
2. In ShipHub: Connect Git (PAT) → Create Project → select this repo/branch.
3. Wait until status is `running`.
4. Open `http://{project}-{workspace}.localhost`.

`GET /` returns `ok`.
